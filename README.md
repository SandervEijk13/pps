# Pokémon Pack Opening Simulator

A small Pokémon pack-opening simulator where players can **buy and open Pokémon packs** with animated opening sequences.

The project also includes a **market database** and a collection system designed to support **all 20,000+ Pokémon cards**.

## Features

* 🎴 Open Pokémon card packs
* ✨ Animated pack-opening experience
* 🛒 Buy packs through the in-game market
* 📊 Market database
* 📚 Full collection system
* 🃏 Support for **20,000+ Pokémon cards**

## Project

This project was created as a game development project to experiment with databases, collection systems, animations, and game mechanics.
